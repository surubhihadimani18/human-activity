# 🏃 Human Activity Recognition Dashboard

This project is an interactive Human Activity Recognition dashboard built using Python and Streamlit.

The dashboard analyzes smartphone sensor data and identifies different human activities.

## 🚀 Features

* Dataset Overview
* Activity Analysis
* Subject-wise Analysis
* Feature Analysis
* Correlation Heatmap
* PCA Visualization
* Machine Learning Classification
* Random Forest Model
* Confusion Matrix
* Feature Importance
* Automated Insights

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Plotly
* Scikit-learn
* Matplotlib

## ▶️ How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

## 📊 Dataset

The dataset contains Human Activity Recognition data with sensor-based features.

The dataset includes:

* 2,947 records
* 561 sensor features
* Subject information
* 6 human activity categories

## 🤖 Machine Learning

The project uses a Random Forest Classifier to predict human activities based on sensor features.

The model evaluation includes:

* Accuracy Score
* Confusion Matrix
* Classification Report
* Feature Importance
